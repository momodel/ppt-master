# 历史档案 · 编辑叙事风 - Design Spec

## I. Canvas Specification

| Property | Value |
|---|---|
| Format | PPT 16:9 |
| Dimensions | 1280 × 720 |
| viewBox | `0 0 1280 720` |
| Margins | 64px outer |

## II. Visual Theme

- Mode: narrative
- Visual style: editorial
- Tone: 档案感、克制、时间纵深
- Colors: parchment #F4EBDD, ink #24211E, cinnabar #A33B2B, brass #B08A4A, mist #D8CDBB
- Typography: "Microsoft YaHei", "Segoe UI", sans-serif

## III. Layout System

- 12 列网格，正文保持窄栏和大留白。
- 朱红索引线、页码和年份作为视觉锚点，不使用仿旧图片。
- 时间线以一条主轴组织，引用页保留大字号原文与出处。

## IV. Image Policy

- 纯图形模板，不使用、上传或生成图片。
