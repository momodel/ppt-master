# 数学几何 · 蓝白推演风 - Design Spec

## I. Canvas Specification

| Property | Value |
|---|---|
| Format | PPT 16:9 |
| Dimensions | 1280 × 720 |
| viewBox | `0 0 1280 720` |
| Margins | 64px outer |

## II. Visual Theme

- Mode: instructional
- Visual style: blueprint
- Tone: 清晰、精确、逐步推演
- Colors: white #FFFFFF, ice #EDF5FF, navy #173B67, blue #2878C8, cyan #32A6B8, orange #E97932
- Typography: "Microsoft YaHei", "Segoe UI", sans-serif

## III. Layout System

- 12 列网格与淡蓝坐标辅助线。
- 定义、推导、结论使用不同层级区域，公式只作为课程内容而非模板样例。
- 图解页突出一个主图形，步骤页保持从左到右的单向阅读。

## IV. Image Policy

- 纯 SVG 几何与文本，不使用、上传或生成图片。
